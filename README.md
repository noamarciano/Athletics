# ⚡ ATHLETICS — Lean Bulk Engine

Premium dark (Nike Training Club style) fitness & nutrition tracker. Single-file web app — React 18 + Tailwind, RTL Hebrew, no build step.

**Features**

- 🏋️ Full Push/Pull A+B routine + Friday run/mobility block — every workout, exercise, set count and rep target is editable in-app
- 📈 Set-by-set weight/rep logging with last-week ghost values (progressive overload at a glance) + weekly tonnage
- ⏱️ Rest timer (1:00 / 1:30 / 2:00 / 3:00) with chime + vibration
- 🏃 Run tracker: unlimited runs per week, auto pace, distance + pace trend chart
- 🥗 Daily Lean Bulk checklist per day-of-week, weekly completion map
- 🗓️ Week time-travel switcher (`< שבוע 28 >`) — full history of every week
- 🔄 Cross-device sync (Mac ↔ iPhone) via a **private GitHub Gist**
- 💾 Local-first: everything persists in `localStorage`; JSON export/import backup

## Run locally

```bash
cd ~/Athletics
python3 -m http.server 4517
# open http://localhost:4517
```

(Or just double-click `index.html` — it works from the filesystem too. Internet is needed for the CDN scripts/fonts.)

## Deploy to GitHub Pages (one time, ~2 minutes)

The repo holds only the app code — **your logs are never committed here**; they sync through a private Gist.

```bash
# 1. Create an empty PUBLIC repo named Athletics on github.com, then:
cd ~/Athletics
git remote add origin https://github.com/<YOUR_USERNAME>/Athletics.git
git push -u origin main

# 2. Enable Pages: repo → Settings → Pages → Source: "Deploy from a branch"
#    → Branch: main, folder: / (root) → Save
```

Your app is then live at `https://<YOUR_USERNAME>.github.io/Athletics/` — open it on any device.

## Enable sync (once per device)

1. Create a token: <https://github.com/settings/tokens/new?scopes=gist&description=ATHLETICS%20Sync> → **Generate new token (classic)**, keep only the `gist` scope (pre-checked), long expiration → Generate & copy.
   *(Must be a **classic** token — fine-grained tokens don't support gists.)*
2. In the app: **סנכרון** tab → paste token → **התחבר**.
3. Repeat on the iPhone with the **same token**. The app auto-creates/finds one private gist (`athletics-data.json`) and merges data both ways (per-week, per-run, last-write-wins).

Sync runs automatically ~2.5s after any change and every time the app regains focus.

## Install on iPhone

Open the Pages URL in Safari → Share → **Add to Home Screen** → you get a standalone ⚡ app with its own icon.
